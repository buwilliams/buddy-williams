# AI Frontier Forecast archive

This directory holds Buddy Williams's public AI Frontier Forecast and supporting research as a dated Markdown snapshot. The [AI Frontier Forecast Space](https://chatgpt.com/space/page_6ac611494cac8191b328ad59ddf12b84) is the current maintained source; access to it may require authorization. This GitHub copy records the source state exported on October 17, 2026. It does not synchronize automatically.

## October 17, 2026 snapshot

- [Forecast](ai-frontier-forecast/2026-10-17/forecast.md): capacity, usage, forecast register and dated changes.
- [Evidence and Releases](ai-frontier-forecast/2026-10-17/evidence-and-releases.md): source links, historical reviews, assumptions and arithmetic.
- [Scenarios and Decisions](ai-frontier-forecast/2026-10-17/scenarios-and-decisions.md): competing adoption mechanisms, tests and calibration.
- [SCM Research](ai-frontier-forecast/2026-10-17/scm-research.md): definitions, purpose allocation, sensitivities and measurement limits.
- [Snapshot notes](ai-frontier-forecast/2026-10-17/snapshot-notes.md): provenance, public-export omissions and validation.

The approximately **0.23× SCM** compares modeled reference-token capacity with a fixed humanity language-throughput convention. It is distinct from the **April 2027 Human–AI 100×** conditional production forecast and the **July 2027 Vals RSI Index** extrapolation. Capacity, usage, useful work and intelligence are different quantities. Sensitivity cases are not confidence intervals.

Only forecast and research content is included. Confidential business strategy, personal material and private account links are excluded. This archive is separate from the repository's website content.
