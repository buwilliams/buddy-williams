## Relevant Projects

### Refine — agentic software delivery system (2026)
Open-source management layer over a fleet of coding agents, orchestrating work across distributed repositories, branches, and nodes, with governance that keeps agent output aligned to product intent before it merges. Rust; installable via CLI or by a coding agent. **Adopted by Insurity for the CXP modernization.** [github.com/buwilliams/refine](https://github.com/buwilliams/refine)

### Forge — agentic delivery tooling (2026)
Claude Code plugin for spec-driven agentic development. Decomposes goals into tasks, launches role-specific subagents with exactly the context each needs, and runs every task through an implement/verify/commit loop with the filesystem as the state machine. An independently generated verifier agent re-checks completed work before it is accepted. [github.com/buwilliams/forge](https://github.com/buwilliams/forge)

### Corpus Council — grounded LLM application (2026)
Python API and CLI routing every response through markdown-defined personas with authority tiers. Retrieval is deterministic — embeddings plus cosine similarity in ChromaDB, top-K injected into every prompt rather than LLM-selected — so answers are grounded in a known context. Anthropic API, sentence-transformers, YAML config. [github.com/buwilliams/corpus-council](https://github.com/buwilliams/corpus-council)

### T-SQL to Spark SQL conversion tool with executing verifier
AI-first migration utility built for an enterprise prospect: a pending/review/approve workflow over AI-converted SQL, plus a PySpark verifier that *executes* converted queries against loaded synthetic data, so correctness is checked end to end rather than syntactically. Generalizes directly to carrier data-migration work. [Walkthrough](https://www.youtube.com/watch?v=9HrwtEgYO-U)
